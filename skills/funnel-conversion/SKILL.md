# 세일즈 퍼널 전환 분석

## 입력 데이터
| 컬럼 | 의미 |
|---|---|
| `opportunity_id` | 딜 ID |
| `team`, `owner_id` | 팀, 담당자 |
| `created_month` | 딜 생성 월 |
| `stage` | 현재 단계: `lead` → `contacted` → `proposal` → `negotiation` → `won` / `lost` |
| `amount` | 예상 금액 |
| `days_in_stage` | 현재 단계에 머문 일수 |

예시: [`sample-data/opportunities.csv`](../../sample-data/opportunities.csv)

## 절차
1. **단계 순서를 고정해요.** `lead < contacted < proposal < negotiation < won`.
2. **도달 수를 세요.** 각 단계에 "도달한" 딜 수 = 현재 그 단계 이상에 있는 딜 수.
   - 데이터에 현재 단계만 있고 `lost`가 어느 단계에서 이탈했는지 모르면, `lost`는 `lead` 도달로만 세고 이 한계를 결과에 밝혀요.
3. **단계별 전환율** = 다음 단계 도달 수 / 현재 단계 도달 수. 전환율이 가장 낮은 구간이 병목이에요.
4. **정체 딜**: 같은 단계에 30일 넘게 머문 진행 중 딜을 금액 순으로 뽑아요. (기준일은 사용자가 바꿀 수 있어요.)
5. **비교**: 팀·담당자별로 같은 표를 만들어, 전체 평균보다 특정 구간 전환율이 크게 낮은 곳을 짚어요.

## 출력 형식
- 한 문장 결론 (예: "proposal → negotiation 전환율이 38%로 가장 낮은 병목입니다.")
- 단계 · 도달 수 · 다음 단계 전환율 표
- 정체 딜 Top 5 (딜 ID, 담당자, 단계, 금액, 정체 일수)
- 다음 액션 제안

## 주의
- 표본이 작은 단위(딜 10건 미만)의 전환율은 "참고용"이라고 표시해요.
