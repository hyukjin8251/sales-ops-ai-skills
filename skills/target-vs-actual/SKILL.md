# 목표 대비 실적 · 생산성 분석

사업 직무(AM, MD, BD 등)가 데이터 분석가 없이도 "우리 팀 지금 어디쯤이야?"에 답할 수 있게 돕는 스킬이에요.

## 입력 데이터
아래 컬럼이 있는 표를 기대해요. 이름이 다르면 사용자에게 매핑을 먼저 확인해요.

| 컬럼 | 의미 |
|---|---|
| `month` | 기준 월 (YYYY-MM) |
| `team` | 팀 |
| `owner_id` | 담당자 |
| `target_revenue` | 목표 매출 |
| `actual_revenue` | 실적 매출 |
| `activities` | 영업 활동 수 (미팅, 콜 등) |

예시: [`sample-data/targets_actuals.csv`](../../sample-data/targets_actuals.csv)

## 절차
1. **기간과 단위를 확인해요.** 질문에 기간(월·분기)과 집계 단위(조직·팀·담당자)가 없으면 묻지 말고 "최근 월 · 팀 단위"로 시작한 뒤, 그렇게 했다고 밝혀요.
2. **집계해요.** 단위별로 `target`, `actual`을 합산한 뒤 계산해요.
   - 달성률 = `actual / target`
   - 갭 = `actual − target`
   - 활동당 매출 = `actual / activities` (생산성 지표)
3. **비율은 합산 후 계산해요.** 담당자 달성률을 평균 내서 팀 달성률이라고 하지 않아요.
4. **정렬과 강조**: 달성률 기준으로 정렬하고, 100% 미만이면서 갭 금액이 큰 단위를 먼저 짚어요.
5. **원인 가설을 제시해요.** 활동 수가 적은지(양의 문제), 활동당 매출이 낮은지(질의 문제)로 나눠서 말해요.

## 출력 형식
- 첫 줄: 한 문장 결론 (예: "9월 광고팀 달성률 92%, 갭 −3,200만 원으로 가장 큽니다.")
- 표: 단위 · 목표 · 실적 · 달성률 · 갭 · 활동당 매출
- 다음 액션 1~3개: 누구와 무엇을 확인하면 좋을지

## 주의
- 금액은 원 단위 숫자를 "만 원/억 원"으로 읽기 쉽게 바꿔서 보여줘요.
- 인센티브나 성과 평가에 쓰이는 숫자라면, 사용한 집계 기준(기간, 포함·제외 조건)을 결과 아래에 꼭 적어요.
